`drupal/meilisearch` lets any Search API index live in [Meilisearch](https://www.meilisearch.com), self-hosted or on Meilisearch Cloud. Views, Facets and every Search API processor keep working: Meilisearch brings typo tolerance, prefix search and relevancy out of the box.

## Features

- Full-text search with typo tolerance and prefix matching
- Keyword, hybrid and semantic search (with an embedder configured in Meilisearch)
- Filters for every Search API condition, including language and datasource
- Facets through [Facets](https://www.drupal.org/project/facets): limits, minimum counts, missing values and OR facets
- Highlighted, cropped excerpts in Views
- Location search through [Search API Location](https://www.drupal.org/project/search_api_location)
- Click analytics on Meilisearch Cloud (submodule)
- Several sites or environments on one Meilisearch instance, with index prefixes

Server-level relevancy settings (synonyms, stop words, ranking rules, embedders) stay in Meilisearch: manage them in the Cloud dashboard, the CLI or the API.
