title: Quickstart
description: From an installed module to a working search page.
---

This walkthrough indexes your site's content and builds a search page at `/search-results` with Views. It assumes the module is [installed](/installation).

<Steps>
  <Step title="Get a Meilisearch instance">
    Use a [Meilisearch Cloud](https://cloud.meilisearch.com) project: the [Meilisearch Cloud guide](/guides/meilisearch-cloud) shows where to find its URL and API key.

    Or run one locally:

    ```bash
    docker run -p 7700:7700 -e MEILI_MASTER_KEY=change-me getmeili/meilisearch:v1.54
    ```

    Its URL is `http://127.0.0.1:7700` (from a Drupal container, use the Meilisearch container's name instead of `127.0.0.1`) and its key is the master key, `change-me`.
  </Step>
  <Step title="Add a server">
    Go to **Configuration → Search and metadata → Search API → Add server**. Name it `Meilisearch`, pick the **Meilisearch** backend, enter the URL and the API key, and save.

    The server page should show **Connection: Connected**. If it doesn't, see [Troubleshooting](/guides/meilisearch-cloud#troubleshooting).
  </Step>
  <Step title="Add an index">
    Go back to **Search API → Add index**:

    - **Index name**: `Content`.
    - **Datasources**: tick **Content**, and choose which content types to index under **Configure the Content datasource**.
    - **Server**: **Meilisearch**.

    Click **Save and add fields**.
  </Step>
  <Step title="Choose the fields">
    Add the fields people search and filter on, for example **Title**, **Body** and **Content type**. Set the **Type** of the fields to search to **Fulltext**; the ones with the highest **Boost** rank first. Keep the others as **String**, **Integer** or **Date**: every field can be filtered and sorted on.

    Click **Save changes**.
  </Step>
  <Step title="Index the content">
    On the index page, under **Index now**, click **Start indexing now**. Afterwards the index shows all items as indexed, and the server page shows the number of documents in Meilisearch.

    New and updated content is indexed as it is saved, because **Index items immediately** is on by default. Otherwise cron indexes it.
  </Step>
  <Step title="Build the search page">
    Go to **Structure → Views → Add view**:

    - **Show**: **Index Content**.
    - Tick **Create a page**, with the path `search-results`, displayed as an **Unformatted list** of **Rendered entity** (or **Fields** if the wizard doesn't offer it).

    Click **Save and edit**, then add a filter **Fulltext search**, tick **Expose this filter to visitors**, and save the view. Visit `/search-results` and search: Meilisearch matches word prefixes and tolerates typos, so `drupl` finds Drupal.
  </Step>
</Steps>
