---
title: DDEV
---

```bash
ddev add-on get kevinquillen/ddev-meilisearch
ddev restart
ddev composer require 'drupal/meilisearch:^1.0@alpha'
ddev drush en meilisearch -y
```

In Drupal, the server URL is `http://meilisearch:7700`; see the [add-on README](https://github.com/kevinquillen/ddev-meilisearch) for its default key.
